1. What the App Does

Noise Diary provides tools to:

  • display an approximate live dB(A) value;
  • start and stop a user-initiated noise event;
  • calculate and save approximate Leq, maximum, and minimum values;
  • add tags and notes and review local measurement history;
  • apply a local calibration offset using a reference meter;
  • export selected records or history as CSV or PDF;

The App does not continuously monitor the environment outside an event you start and does not create or store an audio recording.
