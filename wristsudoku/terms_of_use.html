5. App Description and Functionality

5.1 Puzzle Game

WristSudoku is a 6×6 Sudoku puzzle game designed exclusively for Apple Watch. The App provides 200 deterministic puzzles across four difficulty levels (Beginner, Easy, Medium, and Hard), with 50 puzzles per difficulty.

5.2 Game Features

The App includes the following gameplay features:

  • Note (pencil) mode for marking candidate numbers in cells
  • Up to 3 hints per game to reveal correct answers
  • Full undo support for all moves
  • Real-time error checking with conflict highlighting
  • Related cell and same-value highlighting
  • Game timer with star ratings based on completion time
  • Digital Crown input for number selection
  • Haptic feedback for enhanced interaction

5.3 Statistics

The App tracks your completion progress, best times, and average times for each difficulty level. All statistics are stored locally on your device.

5.4 Fully Offline

All puzzles are generated on-device using deterministic algorithms. The App does not require an internet connection to function and does not use any network services.
